# 页面：流程定义 Definitions（单层列表 · 钻入式浏览 · 版本）

> 从属 `../MASTER.md`。P1 主交付。字段与能力**以 Application.Contracts 真实 DTO 为准**（2026-09-14 逐个核对）。

## 数据现实（决定结构，见 MASTER §8）
- 目录与定义**按层呈现**：一次只看当前目录的直接子项，**目录在前、定义在后** → 一个平铺列表，不做左右分栏、不"全量展开"。
- **搜索与排序只作用于当前层**：关键字命中目录名、或定义的名称 / DefinitionId（后端为 `Name.Contains` 或 `DefinitionId.Contains`）；排序按单一字段串（默认 `CreatedAt desc`）。跨目录全局检索无端点 → 不伪装。
- 无分页（整层返回），无全量计数 → 删除确认不报未经验证的数字。

- 列表列（定义行）：勾选 ｜ 名称 + 描述（过长截断+可查看全文）｜ 类型 ｜ 状态徽标组（`v{Version}` / `已发布 v{PublishedVersion}` / `草稿` / `系统` / `只读` / `可作活动`，§MASTER-3）｜ 更新时间 ｜ 操作 ⋯。目录行无版本/类型徽标。
- 排序下拉/表头明示当前方向；搜索 placeholder 直说作用域「在当前目录（名称 / 定义 ID）搜索」。
- 空态两分支：目录为空 vs 搜索无匹配。

## 列表操作与各表单字段（真实契约）

### 目录
- 行操作（⋯）：**新建子目录 · 重命名 · 移动到… · 删除**。
- 目录移动语义（`MoveFolderDto { ParentId }`，0 = 根目录）：**整棵子树跟随**——其下子目录与定义随父链自动移动，界面不提示"需先搬空内容"。
- 新建/重命名目录表单（`Add/UpdateFolderDto`）：仅 **名称**（必填；同级重名服务端校验回显）。新建时的父级 = 当前所在目录，不在表单露出。
- 删除：强确认，陈述已知的直接子项、不报全量数；非空是否可删以后端返回为准，错误回显框内。

### 定义
- 行操作（⋯）：打开设计器 · 版本 · 发布 · 回滚 · 复制 · **移动到…** · 删除。
- **新建定义**表单（`AddWorkflowDefinitionDto`）：名称*、描述、**类型**（下拉：Workflow / AgentWorkflow / Approval）、可作为活动（开关）。（父目录取当前层；`DefinitionId` 为"向既有定义追新版本"的高级可选字段，常规新建不暴露，如需再议入口。）
- **重命名/编辑**表单（`UpdateWorkflowDefinitionDto`）：名称*、描述、类型、可作为活动——**字段集合与新建一致**，无目录字段。
- **移动语义**：移动作用于该定义的**全部版本行**（不是只搬当前版本）；**系统定义不可移动**（服务端明示拒绝）；**只读不拦截移动**（移动不改内容）→ 所以「只读」定义的菜单里移动仍可用，「系统」的才置灰并解释。
- **`系统 / 只读` 总纪律**：系统 = 编辑/删除/移动均隐藏或禁用并解释；只读 = 仅内容编辑类禁用，移动/复制/查看不受限。

### 版本（行操作「版本」→ 右侧抽屉 Sheet，不打断列表）
- 数据源 `GetVersionList(DefinitionId)`，每行（`WorkflowDefinitionVersionItemDto`）：`v{Version}` · 当前编辑/已发布徽标 · 发布备注（`PublishedNote`，空则不显示）· 发布人（`PublishedBy` 为用户 GUID，无用户查询端点前显示降级态）· 发布时间。
- **回滚**（`RollbackWorkflowDefinitionDto { DefinitionId, DefinitionVersionId }`）强确认：以 v{T} 为源直达目标版本行，交代当前草稿去向。
- **发布**（`PublishWorkflowDefinitionDto { PublishedNote? }`）对话框：目标版本只读 + 备注**选填** + 发布前校验摘要（错误阻断、仅警告需勾选知晓、未校验明示"未校验"）。

### 「移动到…」目标选择器（目录与定义共用同一交互）
- 选择器内 = 逐层平铺浏览（与主列表同款行样式），**根目录作为可选目标**出现在顶层（契约以 0 表示根）。
- 入口预置校验反馈由服务端错误回显，选择器内就地显示并允许换目标：目标不存在/跨空间、**目录移入自身或自身子树**、目标层级**重名冲突**。
- 打开时给一句影响说明：目录 =「其下子目录与定义随之整体移动」；定义 =「该定义的全部版本行一起移动」。
- 纯键盘可完成：遍历、进入/返回层级、选定、确认。

## 覆盖 MASTER 的点
- §8 各约束的主落点；目录移动能力后端已补齐（子树整体跟随、0=根、防环/防跨空间/防重名由服务端校验）。
