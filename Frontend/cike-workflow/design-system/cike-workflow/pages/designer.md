## 画布（结构 / 交互）
- 节点卡片：图标 + 名称（双击行内改名）+ 类型徽标；标题过长截断+悬停全文；宽固定、随摘要增高。
- 端口：入口在左、出口在右；分支出口在端口上显示名称（悬停看完整）。从出口拖到目标即连线；新连线落点避开穿越节点。
- 多选：框选 / 逐项加选；成组移动、成组删除。
- 缩放、平移、缩略导航、适配全图 —— 提供，但**画布内不做入场动画**，编辑即时反馈。
- 拖拽起手设阈值防误触。

## 键盘与拖拽等价（硬约束，MASTER §6）
| 动作 | 指针 | 键盘等价 |
|---|---|---|
| 选中 | 点击 | 方向键遍历节点、回车选中并开属性 |
| 移动 | 拖拽 | 选中后方向键微调 / 加速键大幅移动 |
| 连线 | 端口拖拽 | 选中源→命令「连接」→选目标确认 |
| 删除 | Del | Del（走确认/可撤销） |
- 复制粘贴节点、`保存草稿` 快捷键保留；**发布不设快捷键**（防误触）。
- 读屏可获知：节点总数、当前焦点节点名称与状态。

## 两个层级的编辑面板
### A. 定义级设置（顶栏「设置」入口；对应 `WorkflowDefinitionOptionsValueObject`）
- **变量 Variables**、**输入 Inputs**、**输出 Outputs**：三个"命名项列表"，各支持增删改排序；字段名/类型/默认值按后端定义结构。
- **允许结果 Outcomes**：字符串标签列表（Flowchart 分支出口的可选集合）。
- **自定义属性 CustomProperties**：键值对，未识别项只读兜底 + 警示。
- 与"选中活动"无关，是整张流程的属性。

### B. 节点 Inspector（选中活动；对应 `IActivity` + 类型目录）
- **基础**：名称（`Name`，可空即无标题）、编码（`Code`）、类型（`Type`，只读）与版本（`Version`）。
- **输入 / 输出**：由"活动类型目录"驱动（`IActivity` 的 Input / Output 属性），文本/数字/布尔用受控控件、表达式类用等宽多行；输出可被下游"引用上游输出"选取。目录能力就绪前按样例类型布局设计，接入后结构不变（§8）。
- **高级**：`CustomProperties` 与 `Metadata` 键值；其中 `mergeMode`（`MergeMode`）、`canStartWorkflow`（开关）为**已知的受控项**，给专用控件而非裸 JSON。
- 字段校验就地显示；改动即时反映到「未保存」标记。

## 保存 / 校验 / 发布（交互）
- 「未保存」圆点随改动出现；编辑中**定期静默留存草稿**，留存失败可见且可重试。
- 「校验」按钮手动触发 + 保存后触发；结果进问题面板，分 错误/警告，节点角标同步（色+图标+计数）。
- **发布门控**：存在未解决的校验**错误**时发布禁用并指向问题面板；**未校验**状态明示「未校验」，不得显示为已通过。
- 离开守卫：有改动离开 →「保存草稿并离开 / 直接离开 / 取消」。

## 调试视图（从实例详情进入，只读）
- 同一渲染器叠加执行状态（§3 ActivityStatus 色形文）：当前进行=info 强调（减弱动效下静态）、完成=success、故障=destructive 且可点开异常。
- 与实例执行列表**双向定位**（列表点活动 → 画布居中；反之亦然）。
- 该视图依赖实例数据（§8 缺口），数据不可用时不进入。
