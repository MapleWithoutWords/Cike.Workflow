# 页面：首页 Home（全局概览）

> 从属 `../MASTER.md`。L1 顶级菜单第一项。跨空间视角：回答「全局有没有火情、接下来去哪」。单空间视角在「空间详情」，两者不重复。

## 用户与任务
- 刚登录的管理员 / 运维：一眼扫过各空间健康度 → 进入问题空间或问题实例。
- 不做营销式欢迎语、无引导轮播。

## 结构（自上而下）
```
头部：标题「首页」 + 数据时效条（更新于 ··· ｜ 暂停自动更新 ｜ 刷新）
KPI 行：4 张统计卡（工作空间 ｜ 定义 ｜ 运行中 ｜ 今日故障）
两栏：最近进入的工作空间（卡列表，左宽）   跨空间故障聚焦（表，右窄）
整行：最近执行（实例列表，复用实例行的样式）
```

## 视觉与内容规则
- KPI 卡：数值用等宽字体，故障为 `destructive` 色，其余中性；每卡下一行趋势说明（纯文字「较昨日 +12」，不画趋势图）。卡可点 → 带预置条件跳转到对应列表（故障卡 → 故障实例）。
- **数字的诚实性（本页关键）**：工作空间数量是真实值；定义分布、运行中、故障数在数据能力就绪前一律显示 `--` + 说明 tooltip。占位与真实数字必须视觉可辨（见 MASTER §8，不得用假数糊弄）。
- 最近工作空间卡：名称 + Code（等宽）+ 最近更新；点击进入该空间。**不放定义/实例计数**（无聚合能力）。
- 故障聚焦 / 最近执行：行样式与实例列表一致（同款状态徽标组）；数据未就绪时整块显示「暂不可用 + 原因」，不画空表。
- 空态（全新系统）：「快速开始」三步（新建空间 → 建第一个定义 → 发布运行），每步可直达。

## 交互
- 自动更新默认开启、可暂停；暂停后时效条明示「已暂停」，数据无变化时画面不跳。
- 任一卡片/行的点击都保留可预期的下钻路径：KPI → 列表 → 详情 ≤3 击。

## 验收 checklist
- [ ] 真实数字 / 占位 `--` / 不可用说明 三者一眼可分辨
- [ ] KPI → 故障实例详情 ≤3 击
- [ ] 故障、最近执行空态各有引导，非白板
- [ ] 时效条与暂停开关行为符合 MASTER §5.4
