# 页面：工作空间 Workspaces（列表 + 空间详情）

> 从属 `../MASTER.md`。L1 菜单第二项；工作空间是数据域根，其下挂目录 / 定义 / 实例。覆盖 `/workspaces` 与 `/w/:wsId`。

## A. 工作空间列表 `/workspaces`

- 结构：工具栏（[搜索名称/Code] +「+ 新建空间」） + 卡片网格（宽屏多列、移动单列）。
- 每卡：名称 ｜ Code（等宽小徽标）｜ 描述（过长截断+可查看全文）｜ 最近更新 + 创建人 ｜ 主操作「进入」+ ⋯（编辑/删除）。
- **列表不显示定义 / 实例统计**：无跨层聚合能力，放数字即为假数（MASTER §8）；这里只呈现空间自身的信息。
- 搜索与分页：本页是**全平台唯一走服务端分页 + 关键字 + 排序**的列表（区别于定义页的"整层无分页"）；关键字命中名称/编码，时效条遵循 MASTER §5.4。
- 新建 / 编辑（`Add/UpdateWorkspaceDto`）：`Code` **选填**（`string?`，留空由后端处理，是否自动生成待确认）、**编辑时不可改**（`UpdateWorkspaceDto` 无 `Code` 字段——这是契约事实）；`Name` 必填；`Description` 选填。错误就地显示在字段旁。
- **删除空间（强确认）**：需输入空间名精确匹配才能点确认；影响用**定性描述**（全部目录 / 定义 / 运行记录将不可恢复删除），**不报计数数字**；若后端拒绝（非空等），原因回显在对话框内并给「前往清理」入口。
- 空态：「还没有工作空间」+「新建空间」+ 一句空间语义说明。

## B. 空间详情 `/w/:wsId`（进入空间后的默认页）

- 头部：空间名 ｜ Code ｜ [编辑] ｜ 时效条。
- **统计区（能力受限，诚实呈现）**：
  - 「根目录概览」：仅统计根这一层的直接子目录数与定义数，**明确角注「仅根目录」**；
  - 「定义总数」「实例」：数据能力未就绪 → 显示「暂不可用」+ 原因，**绝不递归拼数**。
- 基本信息卡：名称 / 描述 / 创建人 / 创建·更新时间；Code 旁一键复制。
- 根目录预览卡：列出根层前若干项（目录 / 定义混排），底部「进入目录浏览」→ 跳「工作流定义」。
- 快捷入口：[管理流程定义] [查看全部实例]。
- **危险区**（页面底部，与上方大间距物理分隔 + destructive 描边）：删除此工作空间，复用列表页同一强确认。

## 交互
- 改名 / 改描述保存后，侧栏切换器与面包屑中的空间名同步更新。
- `wsId` 失效或无权限：整页错误态 →「返回工作空间列表」。

## 覆盖 MASTER 的点
- 把 §8 的「无全量计数」落到具体界面：列表零统计、详情统计限定作用域并标注、删除确认定性化。

## 已知缺口（本期 UI 服从）
- 跨空间/跨目录的统计聚合无端点 → 上述统计降级。
- 成员 / 权限后端无能力 → 空间详情**不放占位假 UI**，仅记录为未来扩展位。
