# Cike.Workflow 管理台设计系统 · MASTER

> **设计源真相。** 本文件集只约定三件事：**信息结构、交互行为、视觉（配色/字体/间距/动效）**。
> 不约定前端实现——状态管理、缓存、请求策略、组件/库用法、量化性能预算等均不在本文范围，由实现阶段决定。
> 页面细化放 `pages/<page>.md`，其规则优先于本文件。

- 菜单层级（用户确认）：**首页** ／ **工作空间**（空间详情 · 工作流定义 · 工作流实例）。

- 实现选型（画布 / 路由 / 状态 / 表格等）已另行对齐，**不写入设计文档**。
- **字段真源**：各页的「搜索条件 / 列表列 / 表单字段」一律对照 `Backend/src/Cike.Workflow.Application.Contracts` 的真实 DTO（2026-09-14 核对）；改字段先改契约、再回写设计，不凭记忆编字段。

## 1. 设计定位与气质

- 品类：企业级开发者工具 / 引擎管控台（流程管理员、运维、开发人员）。
- 风格：Minimalism / Swiss——功能主义、高对比、网格秩序、零装饰。
- 刻度：保守变化（variance 2–3）、克制动效（motion 2）、高密度信息（density 8）；**例外**：设计器画布区 density 6。
- 一句话：**控制塔**——数据密集、状态一眼可辨、操作有纪律。

## 2. 设计 Token

### 2.1 颜色（在现有 zinc 变量之上新增；组件内禁止硬编码色值）

现有 token 全部保留原值。新增六对（light / dark）：

| Token | light (`:root`) | dark (`.dark`) | 语义 |
|---|---|---|---|
| `--success` | `oklch(0.55 0.15 152)` | `oklch(0.72 0.15 152)` | 成功 / 完成 |
| `--warning` | `oklch(0.57 0.14 62)` | `oklch(0.78 0.14 75)` | 挂起 / 风险 |
| `--info` | `oklch(0.55 0.16 255)` | `oklch(0.75 0.13 250)` | 进行中 |

- light 侧压到可作徽标文字的明度（AA 目标 ≥4.5:1）；dark 侧提亮降饱和，**不做简单反转**。双主题上线前实测对比度。
- 徽标统一模式：同色「浅底 + 深字 + 浅描边」三件套。

### 2.2 字体

- UI = Geist Sans；数据/代码 = Geist Mono（同家族配对）。
- 字号阶 12 / 13 / 14 / 16 / 18 / 20：页面标题 18–20/600；区块标题 14–15/600；正文与表单 14/400；密集表格 13（**下限，不得低于 12**）。
- 等宽 + 等宽数字仅用于：ID / JSON / 版本 / 耗时 / 计数列。
- 行高：正文 1.5–1.6、表格 1.4；层级靠字重与间距，不靠字号膨胀。

### 2.3 间距 / 圆角 /  elevation

- 4/8 网格：页边距 16/24、卡片内边距 16/24、控件间距 8；表格行高 dense 36px（默认）/ comfortable 44px。
- 圆角沿用既定 0.625rem 体系：徽标中圆角、卡片/浮层大圆角；阴影只用既有刻度（卡片轻、弹层高），不自创。

### 2.4 动效

- 微交互 120ms；弹层入场 180ms、出场 120ms（出快于入）；页面切换 ≈200ms 淡换；列表入场可逐项 30ms 节奏。
- 移动类动效只表达「位置与出现/消失」，**不得让内容跳位**（布局尺寸保持稳定）。
- 减弱动效优先：取消位移与节奏、保留极短淡入；**一切旋转指示（进行中徽标、加载器）转为静态**。

### 2.5 层叠秩序（语义）

页面内容 < 吸顶/固定条 < 画布浮层 < 下拉/气泡/对话框 < 全局通知。只约定相对秩序；任何遮挡焦点或主操作的行为都算错误。

## 3. 状态语义系统（核心视觉资产）

**任何状态 = 色 + 形（图标）+ 文 三重冗余，色彩永不单独承载信息。**

| WorkflowStatus | 徽标 tone | 图标 | 附加 |
|---|---|---|---|
| Pending | muted | `clock` | |
| Executing | info | `loader`（减弱动效下静态） | 列表行左侧进度条 |
| Suspended | warning | `pause` | |
| Finished | success | `check` | 显示耗时 |
| Cancelled | muted | `x` | |
| Faulted | **destructive** | `alert-triangle` | `IncidentCount>0` 红色计数角标 |

| ActivityStatus | tone | 图标 |
|---|---|---|
| Pending | muted | `circle-dashed` |
| Running | info | `loader` |
| Completed | success | `check` |
| Canceled | muted | `x` |
| Faulted | destructive | `alert-triangle` + 故障计数叠加 |

**定义状态徽标组**（列表/详情/设计器共用）：`v{Version}`（latest 高亮）· `已发布 v{PublishedVersion}` · `草稿` · `系统`（锁形 + 解释）· `只读` · `可作活动`。

> 产品纪律：「当前编辑版本」与「线上发布版本」是**两件事实**，任何界面分开展示，不得合并成一个"版本"字段。

## 4. 信息架构与导航

```
L1 全局侧栏（常驻，Logo + 两项）
├─ 首页        /                        跨空间全局概览 → pages/home.md
└─ 工作空间    /workspaces              空间列表 → 点入进入空间上下文 → pages/workspace.md
    └─ L2 空间侧栏（进入某空间后展开，顶部=空间切换器）
       ├─ 空间详情    /w/:wsId                   概览 + 元数据编辑 + 危险区 → pages/workspace.md
       ├─ 工作流定义  /w/:wsId/definitions       单层钻入列表 → pages/definitions-list.md
       └─ 工作流实例  /w/:wsId/instances          列表 + 详情 → pages/instances.md
设计器（全屏独立，不挂任何侧栏）：/w/:wsId/definitions/:defId/designer → pages/designer.md
```

- 空间切换器在 L2 顶部：切换后保持当前功能区（定义→定义、实例→实例）；空间位置在刷新 / 分享后仍成立。
- 面包屑：`首页 › 工作空间 › {空间名} › {区} › {对象 / 目录路径}`；三级以上深度必须给面包屑。
- 当前导航项 = 色 + 字重 + 指示条三重高亮。导航项一律带图标；文字随容器宽度呈现——L2/抽屉为图标+文字，L1 图标栏以图标 + tooltip 承载、文字保留给读屏（窄栏是其形态定义，见 §7）。
- 全局跳转（⌘K 式命令面板）：空间 / 定义 / 目录 / 实例，按当前空间过滤。
- **设置不设顶级导航**：空间级设置并入「空间详情」（重命名 / 描述 / 删除进红色危险区）；新建空间只在工作空间列表页；目录管理嵌在「工作流定义」。
- 破坏性操作（删空间 / 删目录 / 删定义 / 回滚）不进导航，收敛在对象操作菜单与详情页危险区，红色分离呈现。
- 键盘用户可从页首直达主内容；路由切换后阅读焦点落在新内容起点。

## 5. 全局交互纪律

1. **确认清单**（一律强确认，文案含「做什么 + 影响什么」）：删除定义/目录/空间、**发布**（标记已发布版本并影响后续运行）、**回滚**（说明「以目标版本行为源直达」，并交代当前草稿去向）、移动/复制。可撤销的删除给撤销；不可逆的明说不可逆。
2. **反馈闭环**：成功 → 轻提示，不打断输入焦点；失败 → 错误出现在出错的字段旁并说明原因与下一步；多个错误先给可点的汇总再逐一定位。
3. **未保存守卫**：设计器/长表单有改动离开 →「保存并离开 / 直接离开 / 取消」；编辑过程中**定期静默留存**且不阻塞操作，留存失败要可见可重试。
4. **加载与时效**：局部占位（骨架）优先于整页遮罩；会自动更新的数据必须诚实标注「更新于 HH:mm:ss」「已暂停」「已过期」，并允许用户暂停。
5. **批量**：勾选列 + 悬浮操作条；切换目录/翻页/换筛选即清空勾选。
6. **空态**：说明 + 主操作 CTA，区分「没有内容」与「筛选后没有内容」；错误态带重试。
7. **长内容**：换行优先；必须截断时提供查看全文的途径；筛选标签可换行或可点展开——**不允许静默裁掉**。
8. **只读 ≠ 禁用**：只读（系统/锁定）对象可看可复制、编辑入口隐藏并解释原因；禁用对象样式降饱和且给出原因提示。
9. **异步按钮**：提交即进入不可再点 + 进行中表达，防重复触发。

## 6. 可访问性红线（逐条走查）

- [ ] 双主题文字/图形对比达标；**状态永远不依赖颜色单传**
- [ ] 全流程键盘可达：遍历顺序=视觉顺序；焦点永不被吸顶条/浮层遮挡
- [ ] **拖拽类操作必须有键盘等价**（定义移动到目标选择器、画布节点移动/连线）
- [ ] 图标按钮有可读名称；装饰图形对读屏隐形；状态/计数变化以读屏可收到的方式播报
- [ ] 对话框：焦点圈定、可退出、关闭后焦点回到触发处；有明确关闭入口
- [ ] 表格列头携带并播报排序方向
- [ ] 动效与自动更新尊重「减弱动效」偏好
（属性级写法（aria- 等）由实现阶段对照红线落实，不在此规定。）

## 7. 响应式与降级

| 断点 | 行为 |
|---|---|
| ≥1280 | 全量三栏（设计器 palette+canvas+inspector 并排）；L1+L2 侧栏常驻 |
| 1024–1279 | L2 收成图标栏或抽屉（L1 保持窄栏）；设计器 inspector 可为浮层 dock |
| <1024 | L1+L2 合并为单个抽屉；**设计器降级为只读预览** + 「在桌面端编辑」提示 |
| <640 | 宽表横向滚动、名称列保持可见；次要列收进详情；钻入层级全部走面包屑 |

主战场是桌面（≥1280）；移动端按「查看 + 只读」设计，不做移动端编辑。

## 8. 后端能力对设计的约束（2026-09-14 按源码核实）

> 这些是**设计必须服从的现实**，不是实现方案：

- **目录与定义按层浏览**（一次只呈现一个目录的内容，目录在前、定义在后的单层平铺列表）→ 不做「全量展开整棵树」的呈现承诺；**搜索与排序的作用域 = 当前层**，UI 文案必须如实体现（如「在当前目录搜索」）；跨目录全局搜索是后端待补能力，界面不得伪装拥有。
- **无全量计数能力**（某目录/某空间共多少定义、发布/草稿分布）→ 「总数」位置宁显示「暂不可用」或限定作用域并标注（如「仅根目录」）；删除确认用定性描述，不报未经验证的数字。
- 版本模型：编辑版本与线上发布版本并存；回滚=直达目标版本行；发布备注选填 → 对应 §3 的展示纪律与 §5.1 的确认文案。
- **实例域查询与控制端点均未实现** → 实例列表/详情与设计器调试高亮处于「设计就绪、界面缺席」；为取消/挂起保留位置但不放假按钮。
- 活动类型目录（设计器面板与动态表单的数据来源）未暴露 → 面板/表单按「类型目录驱动」的结构设计，先用设计侧样例数据，真实目录接入后结构不变。
- 服务端独立校验能力未确认 → 发布门控只依据「已获得的校验结论」；**未校验状态要明示"未校验"**，不得渲染成"已通过"。
- 所有标识符按**字符串**对待（数值 ID 精度敏感），展示、复制、分享处不得改变其形态。
