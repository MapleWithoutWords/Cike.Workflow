# 右侧工具区统一承载工作流配置与节点属性

原右侧属性面板只在选中节点后有内容，未选中时仍占据宽度却只显示空态；工作流级配置又散落在顶部按钮和独立对话框中。我们决定把右侧改为“窄工具栏 + 单内容面板”的工具区，提供**工作流配置**与**节点属性**两个互斥入口：未选中节点时默认显示工作流配置；选中节点时自动展开并切换到节点属性；取消选中时切回工作流配置，但尊重用户当前的手动展开/折叠状态。固定、尺寸持久化和主动揭示的仲裁继续遵循 ADR 0006。

工作流配置只读展示定义基本信息；变量、输入、输出和工作流结果在此直接编辑，修改即时进入设计器命令栈并参与撤销/重做与后端画布校验。常用字段直接展示，低频字段渐进展开。`customProperties` 是后端扩展载荷，不提供通用编辑器，但加载、保存和发布时必须原样保留。历史版本沿用设计器只读语义。

结构化 `Input` / `Variable` 名称引用在重命名时由前端级联更新，并与重命名合并为一次可撤销操作；JavaScript 与 Liquid 自由文本不做字符串替换，引用错误仅在运行时暴露。删除仍是可撤销操作，不增加二次确认，悬空的结构化引用交由后端画布校验进入问题清单。

## Considered Options

- 在原属性面板头部增加 Tab：被否。折叠后的入口不可见，工作流级与节点级上下文也不够直观。
- 工作流配置与节点属性上下堆叠：被否。右侧宽度有限，两类长表单会互相挤压并混淆层级。
- 为变量、输入、输出继续保留多个独立对话框：被否。配置入口分散，无法形成完整的工作流接口视图。

## Consequences

- ADR 0006 中“取消选中即自动收起属性面板”的规则被本 ADR 修订为“切回工作流配置并保持用户当前开合状态”。
- 原“工作流变量”对话框及顶部独立入口退出主编辑路径，变量编辑统一进入右侧工作流配置。
- 参数类型选择直接消费后端已有的变量类型列表接口；表达式类型继续消费 ExpressionDescriptors 接口。
