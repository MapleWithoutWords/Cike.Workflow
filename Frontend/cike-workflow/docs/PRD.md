# PRD：Cike Workflow 前端 · 第一期「管理控制台」

> 状态：草案待评审。核心章节：**§2 功能大纲**、**§4 字段规则**、**§8 待确认清单**。

## 1. 概述

为工作流系统提供 Web 管理控制台。第一期交付四个模块：**空间管理、目录管理、工作流定义管理（仅元信息）、实例列表（只读）**。可视化设计器、定义详情、实例详情、发布/版本历史均不在本期。

## 2. 功能大纲

```
管理控制台
├── 空间
│   ├── 空间管理页：列表 / 新建 / 编辑 / 删除
│   └── 空间切换器：顶栏下拉，记忆上次选择，URL 携带空间标识
└── 空间内（路由 /w/:workspaceId）
    ├── 浏览页：目录与定义混排列表 + 面包屑 + 当前目录搜索
    ├── 目录：新建 / 重命名 / 移动 / 删除
    ├── 定义：新建 / 编辑 / 移动 / 复制 / 删除
    └── 实例列表：筛选 + 分页，纯只读
```

## 4. 页面详述与字段规则

### 4.1 空间管理页 `/workspaces`

**列表列**：Code、名称、描述、创建时间、操作（编辑/删除）。

**空间表单字段**（长度上限以数据库实体配置为准，下同）：

| 字段 | 必填 | 规则 |
|------|------|------|
| Code | 是 | 1–128 字符；仅小写字母、数字、中划线；全局唯一；**创建后不可修改** |
| 名称 | 是 | 1–128 字符 |
| 描述 | 否 | ≤512 字符 |

**删除规则**：非空空间（含任何目录/定义/实例）禁止删除，按钮禁用并提示原因（**待确认 T2**）。

### 4.2 空间切换器

- 顶栏左侧显示当前空间名，下拉列出全部空间 + 「管理空间」入口。
- 切换空间后停留在当前功能页。
- 打开应用时落地到上次使用的空间；无记忆则进入第一个空间；无空间则进入空间管理页并展示创建引导。

### 4.3 浏览页 `/w/:workspaceId/browse/:folderId?`

- `folderId` 缺省为根目录；面包屑「根目录 / … / 当前目录」可点击跳转。
- 混排列表：**目录在前（按名称排序），定义在后（按更新时间倒序）**。

**目录条目显示**：文件夹图标 + 名称。

**定义条目列**：

| 列 | 说明 |
|----|------|
| 名称 | 定义显示名 |
| DefinitionId | 业务标识，等宽字体展示 |
| 类型 | 徽标：普通工作流 / 智能体工作流 / 审批流 |
| 描述 | 超长省略，悬浮显示全文 |
| 更新时间 | YYYY-MM-DD HH:mm:ss |

**搜索框**：占位文案「搜索当前目录」；≤128 字符；输入即搜（防抖）；匹配目录名称、定义名称、DefinitionId；仅当前目录直属内容。

### 4.4 目录表单（新建/重命名）

| 字段 | 必填 | 规则 |
|------|------|------|
| 名称 | 是 | 1–128 字符；同一父目录下不重名，重名时提示 |

**移动目录**：对话框内单选目标目录树；禁止移入自身及其子目录；根目录可作为目标。

**删除目录**：仅空目录可删；非空目录按钮禁用并提示「请先移出或删除其中内容」（**待确认 T4**）。

### 4.5 定义表单（新建）

| 字段 | 必填 | 规则 |
|------|------|------|
| 所在目录 | 是 | 默认当前浏览目录 |
| 名称 | 是 | 1–128 字符 |
| DefinitionId | 是 | 1–128 字符；字母开头，仅字母/数字/`.`/`_`/`-`；同一空间内唯一；**创建后不可修改** |
| 类型 | 是 | 单选：普通工作流 / 智能体工作流 / 审批流；默认「普通工作流」 |
| 描述 | 否 | ≤512 字符 |
| 可作为活动被引用 | 开关 | 默认关闭；开启后该定义可被其他工作流当作一个活动节点引用 |

**编辑定义**：仅名称、描述、类型、可作为活动被引用 可修改。

**复制定义**：弹出确认框，预填新名称（原名 + "-副本"）与新 DefinitionId（自动生成），用户可修改后确认（**待确认 T7**）。

**删除定义**：二次确认；已被实例使用的定义禁止删除并提示（**待确认 T5**）。

### 4.6 实例列表 `/w/:workspaceId/instances`

**筛选项**：

| 筛选项 | 规则 |
|--------|------|
| 状态 | 多选：等待中/执行中/已挂起/已完成/已取消/失败/已中断；默认全部 |
| 所属定义 | 下拉单选，支持按名称搜索 |
| CorrelationId | 文本输入，精确匹配，≤128 字符 |

**列表列**：名称、所属定义、版本、状态、异常数、创建时间、完成时间。

**状态徽标配色**：等待中/执行中/已挂起=蓝色系（进行中）；已完成=绿色；已取消=灰色；失败/已中断=红色。异常数 >0 时红色高亮。

**无任何行操作，纯只读展示。**

## 5. 通用规则

- **分页**：每页 10/20/50 可选，默认 20。
- **删除**：所有删除均需二次确认，确认框中显示被删对象名称。
- **表单校验**：提交时校验 + 失焦校验，错误红字显示在字段下方。
- **时间格式**：统一 YYYY-MM-DD HH:mm:ss。
- **空状态**：无空间 → 引导创建；空目录 → 「暂无内容」；无实例 → 「暂无实例」；搜索无结果 → 「未找到匹配项」。

## 6. 路由总表

| 路径 | 页面 |
|------|------|
| `/` | 重定向到上次使用的空间或 `/workspaces` |
| `/workspaces` | 空间管理 |
| `/w/:workspaceId/browse/:folderId?` | 浏览页（空间默认首页） |
| `/w/:workspaceId/instances` | 实例列表 |

## 7. 技术前提

- 技术栈：Vue 3 + Vuetify 4 + Pinia + Vue Router + Vue I18n + UnoCSS，pnpm。
- 界面语言：中文为主，i18n 结构预留英文（**待确认 T6**）。
- 本期无登录，直接进入控制台。
