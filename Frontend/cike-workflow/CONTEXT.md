# CONTEXT — Cike Workflow 领域术语表

> 本文件是**术语表（glossary）**，只定义领域概念与它们之间的关系，不含实现细节、文件路径或代码。

## 工作流定义（Workflow Definition）

一个可被反复实例化执行的流程蓝图。对外有两个标识需区分：

- **业务 ID（definitionId）**：字符串，跨所有版本恒定，标识"同一个定义"。
- **版本行 ID（version row id）**：int64，标识"某个定义的某一个具体版本"。API 路径参数 `{id}` 指的是**版本行 ID**，不是业务 ID。

## 版本（Version）

工作流定义的一次内容快照，带递增的**版本号（version）**。每个版本行有两个正交状态：

- **最新版本（Latest）**：`isLatest = true` 的那一行。一个定义只有一个最新版本，它是编辑操作的落点。
- **已发布版本（Published）**：`isPublished = true` 的版本。**已发布版本是不可修改的**——它是一个冻结的快照。

由上述两条派生出两类可能的"最新版本"形态：

- **草稿最新版本（Draft Latest）**：`isLatest = true 且 isPublished = false`。可以就地保存修改。
- **已发布最新版本（Published Latest）**：`isLatest = true 且 isPublished = true`。不能就地修改；对其保存会**派生出一个新的草稿版本**（见"保存"）。

## 画布内容（Canvas Content）

一个工作流版本的可编辑主体，由两部分组成：

- **根活动（Root Activity）**：活动树的根节点，承载画布上的节点与连线（含嵌套容器）。
- **选项（Options）**：版本级配置，其中包含**工作流变量（Variables）**。

## 活动（Activity）

画布上的一个节点，代表流程中的一个步骤（如开始、条件分支、HTTP 请求等）。**容器活动（Container Activity）**可包含子活动，支持**下钻（Drill）**进入其内部画布。

## 节点 Id（NodeId）

活动在工作流树中的层级结构身份，由根到该活动的路径唯一确定：以「父节点 NodeId + 自身活动 Id」逐级拼接而成（根节点即自身活动 Id）。**活动 Id** 是实例身份、创建即生成；**NodeId** 是结构路径身份，二者不可混用。后端在物化时赋值；前端设计器在新增节点时按同一规则计算、并在加载既有画布时回填，两侧算法必须一致。

## 设计器（Designer）/ 画布（Canvas）

编辑工作流定义画布内容的可视化界面。画布有两种模式：

- **可编辑模式**：用于编辑最新版本。
- **只读模式（Read-only）**：用于查看历史版本内容或工作流实例的运行轨迹，不允许改动。

## 画布校验（Canvas Validation）

对当前画布内容（画布根 + 变量）运行的严格正确性检查，与发布前置校验共用同一套规则（开始节点、孤立节点、连线引用、必填输入、变量合法性），递归整棵活动树。只读、不落库、不产生版本；产出一组**校验问题**，空集合即通过。规则的唯一真源在后端，前端不复制。

## 问题清单（Problem List）

设计器画布下方停靠的可折叠面板，是画布校验所产出问题的唯一呈现出口。每条**校验问题**带定位信息（活动 Id / 节点 Id / 名称；工作流级问题如变量非法则为空）与消息，全部为错误级、无警告分级。点击可定位的问题会下钻到该节点所在容器层并选中高亮，同时在画布上给对应节点打错误标记；工作流级问题只展示、不跳转。

## 保存（Save）

把当前画布内容（根活动 + 选项）持久化到**当前打开的版本行**。语义随版本状态分叉：

- 当前是**草稿最新版本**：就地更新该行，版本号不变。
- 当前是**已发布版本**：由于已发布版本不可修改，后端会**派生出一个新的草稿版本并返回其新版本行 ID**；此时前端必须**按新版本行 ID 重新加载整个画布**，之后的编辑落在这个新草稿上。

## 发布（Publish）

把一份画布内容（根活动 + 选项 + 可选**发布备注 publishedNote**）提交为一个已发布版本。发布是一次性提交画布内容的动作，不要求先单独保存。

## 回滚（Rollback）

以某个历史版本为源，使其内容成为新的最新版本。用**业务 ID + 目标版本行 ID**定位来源。

## 工作流实例（Workflow Instance）

工作流定义某一版本的一次具体执行。实例带**运行状态（Status）**：等待中 / 执行中 / 已挂起 / 已完成 / 已取消 / 已故障 / 已中断。实例引用它执行时所依据的**定义版本行 ID（definitionVersionId）**。

## 活动执行记录（Activity Instance Execution Record）

工作流实例中某个活动的一次执行痕迹。通过 **activityId** 与画布上的活动节点对应，带**活动状态（ActivityStatus）**：Pending / Running / Completed / Canceled / Faulted。用于在画布上标记"流程运行到了哪里"。
