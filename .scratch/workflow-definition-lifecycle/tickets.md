# Tickets: 工作流定义生命周期（保存 / 回滚 / 发布 / 移动）

为工作流定义补全保存、回滚、发布、移动四个写操作，打通"草稿就地更新 + 发布打标"的版本生命周期。来源 spec：同目录 `spec.md`。

Work the **frontier**: any ticket whose blockers are all done. 票①完成后，票②和票④可并行；票③需等①②都完成。

---

## ① 保存画布草稿（草稿就地更新）

**What to build:** 设计者在编辑器保存画布内容（Body + Options）：最新版未发布时就地覆盖该行内容；最新版已发布时生成 v+1 新草稿（IsLatest 转移、元数据沿用）——这是版本号增长的唯一路径。同时将 (DefinitionId, Version, IsDeleted) 索引升级为唯一索引（含 EF 迁移），作为并发创建 v+1 的兜底。端点 → 命令 → handler → store 全链路打通，HTTP 集成测试覆盖。

**Blocked by:** 无 —— 可立即开始。

- [ ] 草稿状态下保存：版本号、IsLatest 不变，详情接口返回新画布内容
- [ ] 最新版已发布时保存：版本列表出现 v+1 新草稿，IsLatest 转移到新行，已发布行内容不变
- [ ] 保存只写画布内容，名称等元数据不受影响（元数据走已有 Update 命令）
- [ ] Body 无法通过序列化器往返校验时返回 400
- [ ] IsSystem / IsReadonly 定义保存返回 400
- [ ] (DefinitionId, Version, IsDeleted) 唯一索引迁移已生成并应用
- [ ] 集成测试（HTTP 接缝，状态经查询端点断言）覆盖以上场景，命名 `{Method}_{Condition}_{ExpectedResult}`、条件用中文

## ② 发布工作流定义（含 Core 层画布校验器）

**What to build:** 设计者发布最新草稿：就地打标 IsPublished 并记录 PublishedNote（选填）/ PublishedBy（当前用户）/ PublishedAt。画布严格校验器作为 Core 层新抽象（如 WorkflowValidator）落地——开始节点存在、无孤立节点、变量定义合法、活动必填属性齐全——校验失败返回 400 且错误消息可定位到具体节点/问题。历史已发布标记保留不动。

**Blocked by:** ① 保存画布草稿（发布成功路径的测试数据需先经保存写入合法画布；Add 创建的是空 Flowchart）。

- [ ] 校验器位于 Core 层新抽象，不写在应用层 handler 内
- [ ] 发布成功：版本列表显示该版本 IsPublished、发布人、发布时间、备注
- [ ] 缺开始节点 / 存在孤立节点 / 变量定义非法 / 活动必填属性缺失时发布返回 400，消息可定位
- [ ] 最新行已是发布态再发布返回 400，提示先保存出新草稿
- [ ] IsSystem 定义发布返回 400
- [ ] 后续发布不清除历史版本的已发布标记
- [ ] 集成测试覆盖以上场景（含成功发布需先用①的保存写入合法画布）

## ③ 回滚到历史版本

**What to build:** 设计者把定义回滚到指定历史版本：存在未发布草稿时用目标版本的画布内容覆盖草稿（版本号不变，原草稿内容丢弃——已接受的取舍）；最新版已发布时生成 v+1 新草稿、内容复制自目标版本（已发布行永不改写）。只回滚画布内容，名称等元数据保持当前值。

**Blocked by:** ① 保存画布草稿、② 发布工作流定义（「无草稿回滚」场景需要发布态的最新行，无其他途径构造）。

- [ ] 有未发布草稿时回滚：草稿内容被目标版本覆盖，版本号不变，详情接口可见内容已还原
- [ ] 最新版已发布时回滚：生成 v+1 新草稿，内容来自目标版本，已发布行内容与标记不变
- [ ] 只回滚画布内容（OriginalStringData + Options），元数据保持当前值
- [ ] 回滚目标为当前行时返回 400
- [ ] IsSystem / IsReadonly 定义回滚返回 400
- [ ] 集成测试覆盖以上场景

## ④ 移动到其他目录

**What to build:** 设计者把定义移动到同工作空间的其他目录（folderId=0 表示根目录）：该 DefinitionId 的**所有版本行** FolderId 一起更新，目录树列表接口在新位置可见。目标目录不存在或不属于该工作空间时拒绝。实现与①②③相互独立。

**Blocked by:** ① 保存画布草稿（仅「多版本一起移动」的验收数据需要多版本存在）。

- [ ] 移动后该定义所有版本的 FolderId 更新，目录列表接口在新目录下可见、原目录下不可见
- [ ] folderId=0 移到根目录正常工作
- [ ] 目标目录不存在 / 不属于该工作空间时返回 400
- [ ] IsSystem 定义移动返回 400；IsReadonly 不拦截（移动不改内容）
- [ ] 集成测试覆盖以上场景
